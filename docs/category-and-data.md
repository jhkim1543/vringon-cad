# 카테고리 특화의 이점 · 데이터 플라이휠 분석

작성: 2026-07-29 · 근거: cad.rebuilder.ai 데모 실측 (동일 세션 A/B)

## 1. 카테고리 특화 실측 비교

같은 엔진에서 같은 프롬프트로 두 경로를 실측한 결과.

| 항목 | 범용 생성 (프리폼) | 카테고리 특화 (아키타입) |
|---|---|---|
| "500ml 텀블러" 생성 시간 | 24초 (시안+인벤토리+설계 3콜) | **7.5초** (설계 1콜) |
| 파트 분리 | 2파트 | **4파트** (몸통·캡·실링·라벨) |
| 파라미터 | 3개 | **8개** (몸통·넥·숄더·널링까지) |
| 조립 정합성 | 확률적 — 손잡이 분리·부유 사례, 3회 수정 필요 | **결정적** — 코드에 조립 지식 내장, 실패 0 |
| API 비용/건 | ~$0.05 (이미지+비전 2콜) | ~$0.01 |
| 시뮬레이션 | AI가 넣을 때만 | 카테고리별 내장 (기어비 회전·캡 언스크류) |

특화가 만드는 **편집 깊이**의 사례 — 주얼리(링) 아키타입:
- 범용 생성이면 "스톤 크기" 수준의 파라미터가 나오지만, 특화 아키타입은 **GIA 감정서 규격 18개 파라미터**를 제공: 테이블 %, 크라운각, 파빌리온각, 거들 %, 큐렛 %, 커팅 스타일 3종(브릴리언트/스텝/로즈) × 형상 7종(라운드~페어)
- 이 수준은 도메인 지식을 코드에 넣어야만 가능 — AI 프롬프팅으로는 도달 불가

외부 근거: img2threejs 쇼케이스(Glock)도 페이지에 "범용 권총 바디가 아닌 **Glock-18 전용 어댑터** 사용"을 명시. 업계 최고 품질 데모도 결국 카테고리 어댑터 방식이다.

**결론**: 특화 = ①속도 3배 ②비용 1/5 ③조립 보장 ④도메인급 편집 깊이 ⑤시뮬레이션. 어댑터 1개(0.5~1일 저작)로 해당 카테고리 품질이 영구 보장된다. 범용 생성은 커버리지(어떤 요청도 즉석 처리)를 담당하는 상호보완 관계.

## 2. 데이터 플라이휠 — 무엇이 쌓이고, 무엇이 되나

### 지금 자동으로 쌓이는 것 (`data/telemetry.jsonl`, 서버 외부 차단)

| 이벤트 | 담기는 것 | 학습 데이터로서의 의미 |
|---|---|---|
| `plan` | 프롬프트 → (시안·인벤토리) → **DSL 프로그램 전체**, 라우팅·커버리지·소요시간 | **텍스트→설계 SFT 쌍**. DSL이라 빌드 성공/실패가 자동 라벨 |
| `plan(repair)` | 실패 프로그램 + 오류 → 수정 프로그램 | 오류 수정 학습 쌍 (가장 희소하고 값진 데이터) |
| `edit` | 자연어 수정 지시 → 파라미터 델타 / 프로그램 diff | **지시→편집 SFT 쌍** |
| `client(export)` | 어떤 결과가 STEP/DXF로 다운로드됐나 | **품질 라벨** — 다운로드 = "쓸모 있었다" 신호 |
| 라이브러리 | 사용자가 보관·재편집한 결과물 | 선호 신호 |
| 미매칭 프롬프트 | 카테고리 라우팅에 안 걸린 요청 분포 | **다음 어댑터 우선순위 = 수요 데이터** |

### 왜 유의미한가 — 온프레미스와의 결합

1. **로컬 모델 전환의 연료.** 온프레미스 고객은 결국 외부 API 없는 완전 폐쇄망을 원한다. 위의 프롬프트→프로그램 쌍이 정확히 로컬 소형 모델(7B급) 파인튜닝 데이터다. DSL 출력은 기계 검증이 가능해(빌드 게이트) 저품질 데이터가 자동 걸러진다.
2. **고객사 전용 모델.** 고객사에서 쌓인 데이터는 고객사 서버에만 있으므로, "귀사의 사용 데이터로 귀사 전용 설계 모델이 자란다"는 온프레미스 셀링 포인트가 성립한다. SaaS 경쟁사는 구조적으로 못 하는 약속.
3. **어댑터 로드맵의 근거.** 미매칭 프롬프트 분포가 곧 "다음에 만들 카테고리" 우선순위. 감이 아니라 수요 데이터로 결정.
4. **규모 추정**: 파일럿 10명 × 일 20회 생성 → 월 6,000 쌍 + 수정 지시 ~2,000 쌍. 소형 모델 도메인 SFT에 유의미한 규모(수만 건)까지 3~6개월.

### 수집→활용 사이클

```
사용 → telemetry.jsonl (프롬프트·프로그램·수정·다운로드)
     → 주기 배치: 빌드 게이트로 자동 라벨링/필터
     → ① 어댑터 우선순위 리포트  ② 로컬 모델 SFT 셋
     → 카테고리 추가 + 모델 개선 → 품질↑ → 사용↑ (플라이휠)
```
